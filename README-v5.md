# v5 — 무료 체험(v3) + 앱으로 설치하기 버튼

`/v5/` — v3(구매자 코드 없음, 유튜브 링크 검사)과 같은 화면·같은 판정 API(`/api/analyze-v3`)를 쓰고, v4와 같은 "앱으로 설치하기" 버튼과 v5 전용 앱 설정을 더한 별도 버전입니다.

```
v5/index.html            v3 화면 복사 + 앱 설정 태그 + 설치 버튼 + 안내창
v5/install.js            v4/install.js 와 같은 동작 (서비스 워커 경로만 /v5/)
v5/manifest.webmanifest  v5 전용 앱 설정 (이름 "진짜일까?", 범위 /v5/) — v4 앱과 따로 설치됨
v5/sw.js                 v5 전용 서비스 워커
vercel.json              v5 설정 파일 2개의 헤더만 추가
```

비용 보호(유튜브 앞 10분, 하루 5개 등)는 v3 판정 API 그대로 적용됩니다. 원본·buyer·v2·v3·v4·판정 API는 수정하지 않았습니다.
