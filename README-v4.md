# v4 — 앱으로 설치하기 버튼 버전

`/v4/` — v2(구매자 코드 + 유튜브 링크 검사)와 같은 화면·같은 판정 API(`/api/analyze-v2`)를 쓰고, "앱으로 설치하기" 버튼과 v4 전용 앱 설정을 더한 별도 버전입니다.

```
v4/index.html            v2 화면 복사 + 앱 설정 태그 + 설치 버튼 + 안내창
v4/install.js            기기별 설치 버튼 동작 (안드로이드 크롬 / 아이폰 / 카카오톡 등 / 이미 설치됨)
v4/manifest.webmanifest  v4 전용 앱 설정 (이름·짧은 이름 모두 "진짜일까?", 범위 /v4/)
v4/sw.js                 v4 전용 서비스 워커 (/api/ 는 캐시 안 함)
vercel.json              v4 설정 파일 2개의 헤더만 추가
```

원본(`/`), `buyer.html`, `/v2/`, `/v3/`, 판정 API, 아이콘은 수정하지 않았습니다.
카카오톡에서 외부 브라우저로 자동으로 넘기는 기능은 공식 문서로 확인되지 않아 넣지 않고 안내창만 띄웁니다.
