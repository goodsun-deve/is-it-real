# v3 — 무료 체험 버전 (구매자 코드 없음)

`/v3/` — v2와 같은 기능(글·기사·유튜브 링크 검사)인데 구매자 코드 입력이 없습니다. 판매 전 테스트와 무료 체험용.

```
v3/index.html       코드 입력란이 없는 검사 화면
api/analyze-v3.js   analyze-v2.js 에서 코드 확인을 빼고, 유튜브 사용 제한을 더 엄격하게 한 API
vercel.json         api/analyze-v3.js 항목만 추가
```

환경변수는 v2와 같습니다 (`OPENAI_API_KEY`, `GEMINI_API_KEY`). `ACCESS_CODES`는 v3에서 쓰지 않습니다.

## 비용 보호 (코드가 없으므로 v2보다 엄격)

- 유튜브 영상은 앞 **10분**까지만 분석 (v2는 30분)
- 같은 접속자는 하루 **5개** 영상까지 (서버 메모리 기준이라 서버가 새로 뜨면 초기화되는 대략적 제한)
- 1분에 6회 요청 제한은 그대로
- 링크를 아는 사람은 누구나 쓸 수 있으므로, 테스트가 끝나면 링크를 퍼뜨리지 말고 Google·OpenAI 쪽 월 예산을 꼭 걸어 두세요.
